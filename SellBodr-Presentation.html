Passwordless by Default

WebAuthn / Passkey authentication — no passwords stored, ever.

Auth Flow
1
Register
User enters email and selects a plan. Server issues a WebAuthn registration challenge. User authenticates via biometric (FaceID, TouchID, Windows Hello) or device PIN. Credential stored server-side — no password.
2
Login
User enters email → server issues assertion challenge → browser invokes authenticator → biometric assertion sent back → server verifies signature → JWT issued with plan claim embedded.
3
Authorize
JWT stored client-side. Plan claim (free | pro | org) enforced server-side via EntitlementGuard on every protected route. No client-side trust.
Security Properties
RBAC roles: user and admin. Per-route guards enforce capabilities at the NestJS controller level.
Audit log on every mutation — who changed what, when, from which IP, plan tier at time of action.
Stripe webhook signature verification — all billing events cryptographically verified before plan upgrades are applied.
Graceful passkey fallback — accounts without a registered passkey receive a clear error rather than a silent failure.
Zero passwords in the database — WebAuthn credentials (public keys only) replace traditional password hashes entirely.
Rate limiting on auth endpoints via NestJS throttler guard — brute force protection by default.

Engineering Highlights

Technical decisions that make SellBodr production-ready, extensible, and maintainable.

1
Turborepo Monorepo
apps/web + apps/api share packages/core scoring formulas. pnpm workspaces. Parallel build graph. Single version bump propagates across all consumers.
2
Multi-Provider AI Gateway
Groq / Mistral / Claude / GPT-4 behind a unified interface. Free tier routes to cheaper models. Pro tier unlocks premium providers. Cost tracking per request.
3
WebAuthn / Passkey Auth
Zero password storage. WebAuthn credentials (public key only) replace hashes. Biometric assertion flow. Graceful fallback for accounts without a registered passkey.
4
Leaflet in iframe Sandbox
Leaflet.js requires browser globals unavailable during SSR. Solved by rendering the map inside an iframe that loads a standalone HTML file — clean SSR, no hydration errors.
5
Versioned Scoring Engine
scoreVersion field on every Opportunity row. Formula changes require a version bump. Historical scores remain intact and reproducible for audit or comparison.
6
Turso / LibSQL at Edge
Replaces traditional Postgres with a globally replicated SQLite-compatible edge database. Sub-5ms reads from Vercel edge functions. Drizzle ORM for type-safe queries.
